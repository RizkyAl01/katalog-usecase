# Fungsi Backend & Front End per Kelompok Pengguna

| Kelompok Pengguna | Registrasi | Backend | Front End |
|---|---|---|---|
| **Regulator** (Komdigi & KL) | Registrasi (Log in) | National AI Dashboard: Sebaran & prioritas Use Case berdasarkan dampak, lokasi, sektor/KL, risiko dan monitoring status evaluasi | |
| **Reviewer** (KL) | Registrasi (Log in) | KL : Verifikasi Pengajuan Penyedia Use Case<br>Komdigi : Verifikasi Pengguna Use case, Inovator use case dan Investor | |
| **Penyedia Use Case** | Registrasi (Log in) | Katalog Use Case<br>AI Engineering Sandbox<br>AI Assessment Toolkit<br>Regulatory Sandbox<br>Laporan Insiden Operasional | |
| **Pengguna Use Case** | Registrasi (Log in) | Katalog Kebutuhan Use Case<br>AI Assessment Toolkit<br>Laporan Insiden Operasional | |
| **Inovator Use Case** (Akademisi / Peneliti / Startup) | Registrasi (Log in) | Katalog Riset Use Case<br>AI Engineering Sandbox<br>AI Assessment Toolkit<br>Laporan Insiden Operasional | |
| **Investor** | Registrasi (Log in) | Katalog Use Case (Inovator) terpilih<br>Laporan Insiden Operasional | |
| **Masyarakat** | Tanpa Registrasi | - | Daftar Katalog Use Case<br>Daftar Katalog Kebutuhan Use Case<br>Daftar Riset Use Case |
